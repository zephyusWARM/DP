# DP Visual Prompts

Last updated: 2026-10-06

This file stores visual directions that work well for the learner. They are reusable references, not fixed templates.

## Core protagonist

- young adult East Asian female runner / student;
- clearly adult;
- athletic, fresh, healthy, curious;
- natural anatomy and skin texture;
- not glamour-ad styling;
- not generic "AI anime girl";
- the character should interact with the mathematical structure.

## Core visual language

Preferred:
- cinematic naturalism;
- near-photorealistic;
- warm or dramatic but believable light;
- strong depth layers / atmospheric perspective;
- elegant educational overlays;
- low text;
- formulas, axes, distributions, vectors, or graphs as real visual anchors.

Avoid:
- sterile infographic walls;
- floating random formulas with no geometric meaning;
- generic cyber-neon unless conceptually justified;
- plastic skin;
- repetitive cute style every milestone.

## DP milestone concepts

### M2 — First complete DP mental model
Visual metaphor:
- two neighboring datasets as two nearby worlds / tracks;
- one protagonist crossing a transparent privacy wall;
- randomized mechanism outputs forming two overlapping probability landscapes;
- the attacker stands outside the privacy wall and can only observe the released output;
- visually communicate "hard to distinguish D from D-prime" without turning it into a text-heavy diagram.

### M5 — Adjacency -> sensitivity geometry
Visual metaphor:
- protagonist standing between two adjacent dataset states;
- their query outputs appear as points in vector space;
- l1 and l2 geometric distance structures become part of the landscape;
- sensitivity is the worst allowed jump over one adjacency edge.

### M9 — Mechanisms + clipping / utility
Visual metaphor:
- many feature/gradient vectors arrive with different magnitudes;
- clipping acts like a physically visible radius boundary;
- Gaussian/Laplace noise becomes controlled atmospheric dispersion;
- make bias / variance / utility tradeoff visible without implying clipping itself is noise.

### M12 — Record-level vs user-level
Visual metaphor:
- one user carries many posts / records;
- record adjacency removes one item;
- user adjacency removes the whole person's bundle;
- contribution bounding visibly caps the bundle size;
- preserve the distinction between "one record" and "one person".

### M13 — Independent Homework 1 completion
Visual metaphor:
- runner reaches a ridge / finish line;
- behind her, the course path contains adjacency, output distributions, sensitivity, Laplace/Gaussian noise, clipping, and privacy-unit branches;
- no dense formulas: this is a conceptual victory image.

## Mathematical guardrail

Before any teaching image is generated:
1. identify the exact concept being illustrated;
2. verify every formula / axis / distribution shown;
3. make visual geometry agree with the math;
4. remove decorative math that cannot be verified.

Pretty-but-wrong is a failed image.
